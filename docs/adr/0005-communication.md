# Communication

Hive-strict is a Cargo fact: no cell crate depends on another cell. The consumer owns the leaving SPI in consumer primitive types so the consumer hexagon never imports provider Published Language. `app` calls a consumer API port for each integration event so `app` never writes consumer tables.

## Considered options

- Provider PL structs on the leaving SPI: the consumer hexagon would import provider Published Language.
- Consumer value objects on the leaving SPI: `app` would construct the consumer's domain types instead of its application.
