# Freight

First cells `loads`, `shipments`, and `settlement` live under domain folder `freight` because those three languages pass the cell identity tests. Quote is an aggregate in `loads`, not a cell. `CONTEXT-MAP.md` waits on cell crates so the glossary stays single-context until those languages exist.
