# REST

Public HTTP is REST on axum so GraphQL and MCP stay a later grill. Presentation returns RFC 9457 `application/problem+json` so envelope `context` never reaches the client. Human POST and PATCH require header `Idempotency-Key`, not `CorrelationId`, in a cell table keyed by actor so a retry does not double-write.

## Considered options

- REST `If-Match` / ETag: stream expected version stays event-sourcing law.
- Webhook POST on `Idempotency-Key`: the vendor event id is unique in a separate cell table.
