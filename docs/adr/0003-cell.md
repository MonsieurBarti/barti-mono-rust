# Cell

A cell is one bounded context, one hexagon, that hexagon's tests, and exclusive tables in one schema. Identity is the exclusive language, the exclusive tables, and the Open Host API ports, not team ownership. Too-small, too-big, and chatty stay review rejects because CI cannot see a wrong boundary.
